## Portafolio Web Personal - Frontend

Bienvenido a este repositorio propio donde encontraras la documentacion de mi pagina web **Portafolio Adiel**
Este proyecto esta hecho diseñado y construido desde cero utilizando **HTML5** Y **CSS3**, aplicando conocientos adquiridos en la universidad y propios, sobre buenas practicas y desarrollo web.

## Tecnologias utilizadas
**HTML5:** Estructuración semántica del contenido.
**CSS3:** Diseños y maquetación (Flexbox/CSS Grid, variables CSS, Media Queries).
**Git & GitHub:** Control de versiones y alojamiento de código.

## Estructura de Proyecto
**/css**: Hojas de estilo del proyecto
**/assets**: Recursos gráficos como imagenes e iconos
**/js**: Para futuras integraciones con otros proyectos propios y institucionales
